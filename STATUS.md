# Belarus rental monitor — текущее состояние

## Что работает

- Источники: 🟣 Kufar, 🔵 Realt и 🟠 «Моя реклама».
- Города: Минск, Гомель, Брест, Гродно, Витебск и Могилёв.
- Kufar и Realt работают во всех шести городах; «Моя реклама» — в Гомеле.
- Каждый подписчик выбирает один город и сохраняет собственные фильтры.
- Старые записи подписчиков без города автоматически считаются Гомелем.
- Оценка объявления: цена 50%, расстояние 40%, комнаты 10%.
- Сообщение содержит источник в первой строке (`🟢[Kufar]`), компактный
  адрес, цену в рублях/USD, комнаты, расстояние, число фотографий и ссылку
  с предпросмотром.
- Отписка, повторная подписка, фильтры и сброс фильтров работают через
  постоянную клавиатуру и текстовые команды.

## Архитектура запуска

```text
внешний cron (раз в 5 минут)
        │ GET /?token=...
        ▼
Cloudflare Worker
        ├── активные города из KV subscribers
        ├── Kufar / Realt / Моя реклама
        ├── официальный курс НБРБ (только для Моя реклама)
        ├── KV seen_ids:<source>:<city>
        └── Telegram Bot API → подходящие подписчики города
```

Ленты загружаются параллельно, а Telegram-сообщения отправляются
последовательно. Сбой одной площадки не останавливает две остальные и
фиксируется отдельно в `/status`.

## Миграция состояния

До мульти-источников история Kufar/Гомель хранилась в `seen_ids`. На первом
запуске новой версии она копируется в `seen_ids:kufar:gomel`. Для каждой
новой комбинации источника и города текущая выдача сохраняется без
уведомлений. Поэтому деплой и смена города не вызывают массовую повторную
рассылку.

## Данные площадок

- Kufar: SSR `__NEXT_DATA__`, до 30 объявлений в выбранном поиске.
- Realt: SSR `__NEXT_DATA__`, цены BYN/USD, координаты и полный список фото.
- «Моя реклама»: серверные карточки каталога, BYN, адрес и фото. Координат
  нет, поэтому расстояние равно «не рассчитано». USD считается по НБРБ.

Загрузка HTML ограничена 5 MiB. Пустой результат парсера считается ошибкой
разметки, а не валидной пустой выдачей, и не затирает историю seen-id.

## Конфигурация

- Worker: `kufarresearch`, entry point `src/index.ts`.
- KV binding: `KUFAR_KV`.
- Переменная: `MAX_SEEN_IDS=800`.
- Секреты: `TELEGRAM_BOT_TOKEN`, `ADMIN_TOKEN`.
- Дополнительные ключи для площадок и НБРБ не нужны.
- Встроенного Cloudflare Cron Trigger нет; планировщик внешний.

## Диагностика

- `/?token=...` — реальный прогон;
- `/status?token=...` — последний статус по всем активным лентам;
- `/?debug=1&city=gomel&token=...` — отладка Kufar;
- `/?resetLast=N&source=kufar|realt|moya&city=...&token=...` — сквозной
  тест конкретной ленты.

## Известные ограничения

- «Моя реклама» сейчас доступна только для Гомеля и не даёт координат.
- Точки центра для новых городов — центральные площади; для Гомеля оставлена
  согласованная точка у Универмага.
- Нет распределённой блокировки параллельных прогонов. При одном внешнем
  планировщике это не создаёт гонку.
- HTML площадок может измениться; `/status` покажет отдельную сломанную
  ленту, не выключая остальные.
