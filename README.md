# Belarus rental monitor

Cloudflare Worker следит за новыми объявлениями долгосрочной аренды и
отправляет их в Telegram. Состояние хранится в Workers KV, запуск делает
внешний HTTP-планировщик.

## Источники и города

| Источник | Города | Данные |
|---|---|---|
| 🟣 Kufar | Минск, Гомель, Брест, Гродно, Витебск, Могилёв | цена, адрес, комнаты, координаты, фото |
| 🔵 Realt | те же шесть городов | цена, адрес, комнаты, координаты, фото |
| 🟠 Моя реклама | Гомель | цена, адрес, комнаты, фото |

«Моя реклама» не публикует координаты в каталоге, поэтому расстояние для
неё отображается как «не рассчитано». Для пересчёта BYN в USD используется
публичный официальный API НБРБ; отдельный ключ не нужен.

Проверяются только города, выбранные активными подписчиками. У старых
подписчиков автоматически остаётся Гомель.

## Формат Telegram-сообщения

```text
🟢[Kufar] Цена: 850р (276 USD)
Адрес: Ветковская ул., 2
Кол-во комнат: 2️⃣
Расстояние до Центра: 0,7 км

📸 Фотографий: 15
Ссылка на объявление
```

Цена и адрес выделяются жирным, последняя строка является ссылкой. Если
страница объявления содержит фотографии, Telegram получает ссылку с
крупным предпросмотром. Это одно текстовое сообщение, поэтому push содержит
цену, адрес и комнаты, а не подпись вида «3 фотографии».

Цветная оценка: цена — 50%, расстояние — 40%, комнаты — 10%. Ценовые
границы: 150/200/250/300 USD; расстояние: 2/5 км; две и более комнаты дают
максимальный балл за комнаты.

## Команды и кнопки бота

- `/start` / `/stop` — включить или остановить уведомления;
- кнопка `🏙 Город: …` или `/city Брест` — выбрать один из шести городов;
- `🔍 Фильтры` / `/filters` — открыть фильтры;
- `♻️ Сбросить фильтры` / `/clearfilters` — убрать фильтры;
- `/price 100-300`, `/price off` — свой диапазон цены в USD;
- `/rooms 1,2`, `/rooms off` — число комнат (`4` означает `4+`).

После смены города первая текущая выдача принимается за базовую и не
рассылается. Это не даёт старым объявлениям нового города прийти залпом.

## Структура

```text
src/
  cities.ts           — города, алиасы, центральные точки и URL-параметры
  sources.ts          — реестр лент источников по городам
  kufar.ts            — парсер Kufar
  realt.ts            — парсер Realt
  moya.ts             — парсер «Моей рекламы»
  rates.ts            — официальный курс USD из НБРБ
  fetcher.ts          — ограниченная по размеру загрузка публичных страниц
  hotness.ts          — оценка, расстояние и формат сообщения
  subscribers.ts      — подписчики, город и фильтры в KV
  filter-ui.ts        — Telegram-клавиатуры
  telegram-webhook.ts — команды и callback-кнопки
  telegram.ts         — отправка уведомлений
  state.ts            — seen-id по источнику/городу и статус запуска
  monitor.ts          — загрузка → парсинг → diff → рассылка
  index.ts            — HTTP-маршруты Worker
```

## Установка и деплой

```bash
npm install
npx wrangler login
npm run typecheck
npm test
npm run deploy
```

В `wrangler.toml` уже указан KV namespace. Нужны два секрета:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put ADMIN_TOKEN
```

- `TELEGRAM_BOT_TOKEN` выдаёт BotFather;
- `ADMIN_TOKEN` — длинная случайная строка для защиты всех URL Worker.

Других API-ключей нет. Для локальной проверки можно скопировать
`.dev.vars.example` в `.dev.vars` и вписать тестовые значения.

Webhook Telegram регистрируется один раз:

```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://kufarresearch.calm4.workers.dev/telegram-webhook?token=<ADMIN_TOKEN>"
```

## Планировщик и диагностика

Внешний сервис (например, cron-job.org) должен раз в пять минут открывать:

```text
https://kufarresearch.calm4.workers.dev/?token=<ADMIN_TOKEN>
```

Cloudflare Cron Trigger не используется: его IP-пул Kufar периодически
блокировал. GitHub Actions schedule также оказался ненадёжным для этого
проекта.

Служебные URL:

- `/status?token=...` — последний запуск и результат каждой ленты;
- `/?debug=1&city=gomel&token=...` — диагностика Kufar для города;
- `/?resetLast=1&source=realt&city=gomel&token=...` — удалить последний id
  конкретной ленты для сквозного теста следующего запуска.

При деплое старый ключ `seen_ids` автоматически переносится в
`seen_ids:kufar:gomel`. Новые ленты Realt/«Моей рекламы» сначала создают
тихую базовую точку, поэтому повторной рассылки старых объявлений нет.

```bash
npm run typecheck
npm test
npm run dev
npx wrangler tail
```

Тесты не требуют реальных секретов или сети. Реальные страницы всех лент
следует дополнительно проверить перед деплоем, поскольку сайты могут менять
HTML-разметку.
